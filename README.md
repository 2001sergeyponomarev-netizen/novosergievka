# Made in USSR — План посевов Новосергеевки (FS25)

Интерактивный сайт с кликабельными полями №1–30 и планом посевов на четыре игровых года.

## Открыть сайт

После включения GitHub Pages: https://2001sergeyponomarev-netizen.github.io/novosergievka/

## Включить GitHub Pages

1. Откройте Settings → Pages в этом репозитории.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Выберите ветку main и папку / (root), затем Save.
4. Дождитесь публикации (обычно несколько минут).

## Как администратору менять посевы

1. Откройте `data/plan.csv` в репозитории.
2. Нажмите значок карандаша Edit.
3. Измените строку нужного поля: `field` — номер, `owner` — хозяйство, `year1`–`year4` — культуры, `notes` — заметки.
4. Нажмите Commit changes. Сайт автоматически загрузит обновлённые значения при следующем открытии или обновлении страницы.
5. После внесения настоящего плана измените `data/settings.json`: `"demoMode": false`.

Данные сейчас **демонстрационные**, не являются утверждённым севооборотом.

## Доступ

Игроки видят только просмотр. Изменение CSV возможно только через GitHub для пользователей с правами записи. Не выдавайте другим участникам права Write/Maintain/Admin на репозиторий.

**Важно:** публичный GitHub Pages не может обеспечить безопасное редактирование через пароль, встроенный в HTML. Для полноценной админ-панели прямо на сайте понадобится отдельная авторизация и серверная база данных.

## Карта

Пока используется интерактивная схематичная карта (SVG), без оригинального фонового изображения. Геометрия зон приближённая и требует проверки по игровой карте. Особенно проверьте поле №28.

Файлы: `index.html` — сайт, `data/plan.csv` — посевы, `data/settings.json` — признак демонстрационных данных.
