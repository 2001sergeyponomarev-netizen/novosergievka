# Made in USSR — План посевов Новосергеевки (FS25)

Интерактивный сайт по карте Новосергеевки: нажми на поле и узнай культуру на каждый из четырёх игровых годов.

**Для игроков:** https://2001sergeyponomarev-netizen.github.io/novosergievka/

**Панель администратора:** https://2001sergeyponomarev-netizen.github.io/novosergievka/admin.html

## Изменение плана (администратор)

1. Откройте ссылку **Панель администратора** на сайте.
2. Создайте **fine-grained personal access token** на https://github.com/settings/personal-access-tokens/new
   - Resource owner: `2001sergeyponomarev-netizen`
   - Repository access: **Only select repositories** → `novosergievka`
   - Repository permissions: **Contents → Read and write** (остальные разрешения — без дополнительных прав).
   - Желательно установить срок действия токена и обновлять его при необходимости.
3. Вставьте токен в поле «GitHub fine-grained token» и нажмите «Подключить GitHub». **Никому не отправляйте токен и не добавляйте его в код или сообщения.**
4. Выберите поле №1–30; укажите хозяйство, культуры на четыре года и примечание. Можно быстро назначить культуру нескольким полям одновременно.
5. Нажмите **«Опубликовать план на сайте»**. Изменения сохраняются в `data/plan.csv` в ветку `main` и GitHub Pages автоматически запускает публикацию.
6. Когда план будет настоящим, поставьте галочку «Это утверждённый план: убрать отметку ДЕМО», затем сохраните.

Для хранения резервной копии есть **«Скачать резервную копию CSV»**.

## Права доступа и безопасность

- Игроки могут смотреть карту и карточки полей без авторизации.
- Код сайта и панель администратора доступны публично, **но запись разрешена только владельцу GitHub-токена, у которого есть Contents: write на репозитории**. Открыть страницу панели недостаточно, чтобы что-либо изменить.
- Токен вводится только в собственном браузере и используется для запросов напрямую к `api.github.com`. Код панели не использует `localStorage` или `sessionStorage` для хранения токена; после перезагрузки его потребуется ввести снова.
- **Не вводите пароль GitHub**. Используйте только fine-grained token для одного репозитория.
- Если токен скомпрометирован, немедленно отзовите его в настройках GitHub.
- Не выдавайте игрокам право `Write` или выше в репозитории.

## Файлы

- `index.html` — публичный сайт с интерактивной картой
- `admin.html` — визуальная панель администратора с GitHub API
- `assets/a_clean_high_resolution_top_down_aerial_map_over-1.png` — подготовленная аэрофотокарта
- `data/plan.csv` — основная таблица посевов

## Оговорки

Посевы в CSV сейчас **демонстрационные**, не утверждённый план севооборота. Геометрия интерактивных контуров приблизительная; пожалуйста, проверьте совпадение со скриншотом и номера полей, особенно поле №28.

## GitHub Pages

В Settings → Pages источник должен быть **Deploy from a branch**, ветка `main`, папка `/ (root)`.
