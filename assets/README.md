# Изображение карты
В эту папку загрузите **один файл**: `novosergeevka-map.png`.

Прямая страница загрузки (GitHub в браузере): https://github.com/2001sergeyponomarev-netizen/novosergievka/upload/main/assets

Интерактивный сайт уже готов показывать фото-карту: как только файл появится, он автоматически заменит схему. Кликабельные области, план посевов и поиск сохранятся.

Используйте подготовленное изображение размером 1536×1024.
